Colorful CSS Animation

A simple and creative animation project built with HTML and CSS in collaboration with my instructor.

About the Project

This project explores how CSS can be used to create colorful visual effects and animations. It was a hands-on opportunity to practice front-end development and understand how styling brings a design to life.

Technologies Used

- HTML5
- CSS3

Collaboration

My instructor worked on the HTML structure, while we collaborated on the CSS styling and animation.

How to Run

1. Clone or download this repository.
2. Open the project folder.
3. Open "index.html" in your web browser.

What I Learned

- Practicing CSS styling and animation.
- Understanding how HTML and CSS work together.
- Gaining experience through collaboration and hands-on development.
